# juanveralabs/tap

Homebrew formulae for [juanveralabs](https://github.com/juanveralabs) tools.

```bash
brew install juanveralabs/tap/apple-cli
brew install juanveralabs/tap/workhorse
```

| Formula | What it is |
|---------|------------|
| [`apple-cli`](https://github.com/juanveralabs/apple-cli) | On-device speech-to-text and LLM text generation for macOS 26+ |
| [`workhorse`](https://github.com/juanveralabs/workhorse) | Zero-dependency coding agent that runs scoped tasks on cheap models |
